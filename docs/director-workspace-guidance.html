Common issues

The page is still loading

Check the network connection and try again. Share any reference code with support.

OCR read a value incorrectly

Compare extracted values with the source document, correct them, and verify before saving.

Sign out is taking too long

Wait for the request. If retry guidance appears, try again or contact support with the displayed reference.

Acceptance criteria

  • Tour suppression is stored per user and role.
