Execution

  1. Record the exact deployed commit and approved remote target.
  2. Install one signed Android and one signed iOS build.
  3. Verify the five real role/organisation/site relationships in the authoritative database; transfer credentials only through the controlled channel.
  4. Run every scenario with explicit human OCR review.
  5. Store detailed evidence externally and place safe relative references in output/uat-private/ocr-device-uat.json.
  6. Run the gate:
npm run validate:ocr-device-uat -- output/uat-private/ocr-device-uat.json

Stop conditions

Stop on privacy leakage, cache residue, permission bypass, silent cancellation fallback, access-control failure, automatic OCR application, incomplete rollback, mutable ready evidence, unredacted audit output, or an unprovable build/commit.

Acceptance

Release readiness requires 25 passes, zero structural/privacy issues, signed Android and iOS evidence, all five real access variants, and safe evidence references. Synthetic contract fixtures test only the validator and are never UAT completion evidence.
