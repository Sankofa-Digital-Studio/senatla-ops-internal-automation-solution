The updated front page has a persistent H1, a non-interactive loader tied to real work, explicit image dimensions, one document-level vertical scroller, and no horizontal overflow at 390 by 844. Gmail now requires an operational session and retains the requested return URL during sign-in.

Findings and fixes

High priority

  • Guarded the internal Gmail route with existing authentication checks.
  • Removed the 900 ms landing delay and 150 ms simulated resource delay.

Accessibility and consistency

  • Changed the persistent hero heading to H1 and hid inactive content from assistive technology during loading.
  • Associated login labels with their inputs and removed the irrelevant recovery-mode password toggle.
  • Raised desktop landing targets from 40 to 44 pixels and gave the mobile menu explicit button semantics.

Scrolling and images

  • Removed competing public-page and application-shell vertical scrollers.
  • Enabled route scroll restoration and anchor navigation.
  • Added intrinsic image dimensions, high fetch priority for the welcome image, lazy loading below the fold, and asynchronous decoding.

Residual risk: authenticated modal focus management and full role-specific keyboard journeys need deterministic seeded accounts. The product has no carousel or swiper component in this version; swipe navigation would be a new evidence-lightbox feature.

Three-pass verification

  1. Baseline: live desktop and mobile review confirmed working CTAs and images, then isolated missing heading semantics, small targets, and avoidable delay.
  2. Implementation: TypeScript, lint, production build, and focused browser flows passed after the fixes. The full inherited browser unit suite remains at 138 of 142: one pre-existing login-mode assertion and three SiteReadiness tests without a RUNTIME_CONFIG provider fail outside this pass.
  3. Challenge: mobile remeasurement exposed an unnecessary stable scrollbar gutter; it was restricted to tablet and desktop widths.

Updated mobile evidence: no clipped headings or CTAs, no undersized visible controls, no broken images, no horizontal overflow, and only the document as a vertical scroller.
