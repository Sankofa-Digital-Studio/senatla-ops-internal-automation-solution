How the source files are used

The supplied workbooks inform layout and section names. They do not supply proposal quantities, rates, percentages, asset records or personnel data. All formats start with the client label Harmony Gold Mines; confirm the exact contracting entity before external issue.

West Gold and Tau Mine use the existing workspace phase structure as a baseline. The supplied ZIP did not contain a workbook named for either project, so these formats are not claimed as exact copies of signed spreadsheets.

Director workflow

  1. Select a template and edit project, client and reference details.
  2. Add, rename or remove sections and items. Enter units of measure, quantities and rates.
  3. Set P&G, contingency, profit and VAT percentages. They start at zero.
  4. Review the live summary and open Preview spreadsheet to check line amounts and subtotals.
  5. Use Export Excel for a formula-based workbook or Save PDF for an immediate draft download.

Checks before issue

  • Verify the legal client name, scope and current rates.
  • Review the unpriced-line count; blank fields are not filled from historical workbooks.
  • Check the commercial percentages and tender total.
  • Both exports are drafts. This builder does not save a proposal to the database.
